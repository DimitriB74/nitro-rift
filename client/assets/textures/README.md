# Textures

Déposez ici les textures. Elles sont facultatives : sans elles, les surfaces
utilisent des couleurs unies définies dans `client/src/render/piste.js`.

## Fichiers attendus

| Fichier | Usage |
|---|---|
| `asphalte_couleur.jpg` | Couleur de la route |
| `asphalte_normale.jpg` | Carte de normales de la route |
| `asphalte_rugosite.jpg` | Rugosité de la route |
| `sable_couleur.jpg` | Hors piste du Canyon |
| `neige_couleur.jpg` | Hors piste de la Montagne |
| `glace_couleur.jpg` | Plaques de glace |
| `beton_couleur.jpg` | Murs et structures |
| `roche_couleur.jpg` | Parois du Canyon |

## Contraintes

- Format **JPEG** pour la couleur, **PNG** si un canal alpha est nécessaire.
- Textures **carrelables** (seamless), 1024 × 1024 ou 2048 × 2048.
- Visez moins de 500 Ko par fichier.
