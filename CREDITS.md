# Crédits

## État actuel

**Aucun asset externe n'est utilisé pour l'instant.** Tout ce qui s'affiche et
tout ce qui s'entend est généré par le code :

- les voitures sont modélisées à la volée (`client/src/render/voiture.js`) ;
- les circuits sont maillés depuis leurs données (`client/src/render/piste.js`) ;
- les ciels sont des dégradés procéduraux (`client/src/render/scene.js`) ;
- les sons seront synthétisés avec la Web Audio API (étape 11).

## À remplir en ajoutant des assets

Chaque fichier ajouté dans `client/assets/` doit être crédité ici, avec son
auteur, sa source et sa licence. Les README de chaque dossier d'assets listent
les fichiers attendus et les sources conseillées.
